# Somewhere Between Dreams

A dark, gothic personal journal built as a static site for GitHub Pages.

## Publish with GitHub Pages

1. Open your repository: https://github.com/YumeSakurai/somewherebetweendreams
2. Choose **Add file → Upload files**.
3. Extract this ZIP on your computer.
4. Upload `index.html` and the entire `assets` folder (not the ZIP itself).
5. Commit the files to the `main` branch.
6. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`.

The site should then appear at:
https://yumesakurai.github.io/somewherebetweendreams/

## Images

- `assets/images/moon-cat.png` is the decorative homepage illustration.
- `assets/images/the-muse.png` is the image supplied for the Muse section.

## Editing

The homepage is `index.html`; its visual styling is in `assets/css/style.css`.
The title uses the Ballet Google Font and the rest of the text uses Cormorant Garamond.
